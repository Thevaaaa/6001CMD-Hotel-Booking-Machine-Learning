# Dataset Information

## Dataset Name

Hotel Booking Demand Dataset

## Dataset Source

The dataset used for this project was obtained from Kaggle.

**Kaggle Dataset URL:**

https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand

## Dataset Description

The Hotel Booking Demand dataset contains hotel booking records from two hotel properties. It includes information relating to booking characteristics, guest information, arrival details, distribution channels, room types, deposit arrangements, previous booking behaviour and other booking-related attributes.

The original dataset contains:

- 119,390 records
- 32 variables

## Target Variable

The selected target variable is:

`is_canceled`

The target represents whether a hotel booking was cancelled:

- `0` = Booking was not cancelled
- `1` = Booking was cancelled

The problem is therefore formulated as a binary classification task.

## Original Academic Source

Antonio, N., de Almeida, A., & Nunes, L. (2019). Hotel booking demand datasets. *Data in Brief, 22*, 41–49.

DOI:

https://doi.org/10.1016/j.dib.2018.11.126

## Data Handling

The original CSV dataset is not stored in this GitHub repository. The dataset was downloaded from the source above and analysed using Python and Jupyter Notebook.

No Excel-based data modification was used for the exploratory data analysis.

The complete analysis and preprocessing code are available in the project's Jupyter Notebook.
